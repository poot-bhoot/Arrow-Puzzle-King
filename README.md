# Arrow Puzzle King (Android Native Kotlin + Jetpack Compose)

## Bina PC ke Mobile se `.apk` kaise banayein (GitHub Actions):
1. Is ZIP file ko apne phone mein extract karein.
2. Phone ke browser mein **github.com** khol kar login karein aur **New Repository** banayein (naam kuch bhi rakhein, jaise `arrow-puzzle-king`).
3. Saari extracted files aur folders (`.github` folder samet) us repository mein upload karke **Commit changes** dabayein.
4. Repository ke upar **Actions** tab par jayein — wahan **Build Arrow Puzzle King APK** automatic chal raha hoga (2–3 minute lagenge).
5. Green tick aane par us build par click karein aur niche **Artifacts** section se **`ArrowPuzzleKing-APK`** download karke install kar lein!
